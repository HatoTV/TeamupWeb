# Suivi « Tips pour jouer {champion} » (page Builds)

Consigne des sous-agents de recherche : `tools/community-tips/play-brief.md`. Méthode et format : `tools/community-tips/README.md`, section « Fiches « Tips pour jouer {champion} » (`play/`) ». Données : `public/assets/data/community-tips/play/`, notes : `tools/community-tips/notes/play/`. Contrôle : `npm run tips:check`.

Reprise après interruption : prendre le premier lot « à faire », lancer la recherche (un sous-agent par lot), relire, `npm run tips:check`, mettre ce fichier à jour, un commit par lot.

Légende : ✅ fait · ⚠️ fait avec peu de contenu vérifié · ⏳ à faire · ❌ pas de fichier (moins de 2 entrées vérifiées)
